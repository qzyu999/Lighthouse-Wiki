part

Product catalog of parts available in the supply chain.

Layer: Core Type: Entity Rows: 2,000 Related: partsupp, lineitem

Schema

ColumnTypeDescription
p_partkeyINTEGERPrimary key — unique part identifier
p_nameVARCHARPart name (color + type combination)
p_mfgrVARCHARManufacturer
p_brandVARCHARBrand identifier (Brand#NN)
p_typeVARCHARType description (e.g. ECONOMY ANODIZED STEEL)
p_sizeINTEGERPart size (1–50)
p_containerVARCHARContainer type (SM BOX, LG CASE, etc.)
p_retailpriceDECIMALRetail price
p_commentVARCHAROptional remarks

Business rules

  • p_partkey is the primary key (unique, not null)
  • p_size must be between 1 and 50
  • p_retailprice > 0
  • Referenced by partsupp.ps_partkey and lineitem.l_partkey
  • A part can be supplied by multiple suppliers (many-to-many via partsupp)

Example queries

Parts by brand and type

SELECT p_brand, p_type, COUNT(*) AS cnt
FROM part
GROUP BY p_brand, p_type
ORDER BY cnt DESC
LIMIT 10;

Average retail price by container

SELECT p_container, AVG(p_retailprice) AS avg_price, COUNT(*) AS cnt
FROM part
GROUP BY p_container
ORDER BY avg_price DESC;
