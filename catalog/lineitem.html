lineitem

Order line items — the largest fact table containing individual shipment records.

Layer: Core Type: Fact Rows: 60,000 Related: orders, part, supplier

Schema

ColumnTypeDescription
l_orderkeyINTEGERFK → orders.o_orderkey (part of composite PK)
l_partkeyINTEGERFK → part.p_partkey
l_suppkeyINTEGERFK → supplier.s_suppkey
l_linenumberINTEGERLine number within the order (part of composite PK)
l_quantityDECIMALQuantity ordered
l_extendedpriceDECIMALExtended price (quantity × retail price)
l_discountDECIMALDiscount percentage (0.00–0.10)
l_taxDECIMALTax rate (0.00–0.08)
l_returnflagVARCHARReturn status: A (accepted), R (returned), N (not yet shipped)
l_linestatusVARCHARLine status: O (open), F (fulfilled)
l_shipdateDATEActual ship date
l_commitdateDATECommitted delivery date
l_receiptdateDATEActual receipt date
l_shipinstructVARCHARShipping instructions (DELIVER IN PERSON, COLLECT COD, etc.)
l_shipmodeVARCHARShipping mode: TRUCK, SHIP, AIR, MAIL, RAIL, REG AIR, FOB
l_commentVARCHAROptional remarks

Business rules

  • Composite primary key: (l_orderkey, l_linenumber)
  • l_orderkey must reference a valid orders.o_orderkey
  • l_partkey must reference a valid part.p_partkey
  • l_suppkey must reference a valid supplier.s_suppkey
  • (l_partkey, l_suppkey) must exist in partsupp
  • l_extendedprice = l_quantity × part retail price
  • l_discount between 0.00 and 0.10
  • l_tax between 0.00 and 0.08
  • Revenue formula: l_extendedprice * (1 - l_discount)
  • l_shipdate ≤ l_receiptdate

Example queries

Daily revenue (TPC-H Q1 style)

SELECT l_shipdate,
       SUM(l_extendedprice * (1 - l_discount)) AS revenue,
       SUM(l_quantity) AS total_qty
FROM lineitem
WHERE l_shipdate BETWEEN '1994-01-01' AND '1994-12-31'
GROUP BY l_shipdate
ORDER BY l_shipdate;

Revenue by ship mode

SELECT l_shipmode,
       COUNT(*) AS line_count,
       SUM(l_extendedprice * (1 - l_discount)) AS revenue
FROM lineitem
WHERE l_shipdate >= '1995-01-01'
GROUP BY l_shipmode
ORDER BY revenue DESC;
