customer

Buyer accounts that place orders in the supply chain.

Layer: Core Type: Entity Rows: 1,500 Related: nation, orders

Schema

ColumnTypeDescription
c_custkey123INTEGERPrimary key — unique customer identifier
c_nameVARCHARCustomer name
c_addressVARCHARStreet address
c_nationkeyINTEGERFK → nation.n_nationkey
c_phoneVARCHARPhone number
c_acctbalDECIMALAccount balance
c_mktsegmentVARCHARMarket segment (AUTOMOBILE, BUILDING, FURNITURE, HOUSEHOLD, MACHINERY)
c_commentVARCHAROptional remarks

Business rules

  • c_custkey is the primary key (unique, not null)
  • c_nationkey must reference a valid nation.n_nationkey
  • c_mktsegment is one of: AUTOMOBILE, BUILDING, FURNITURE, HOUSEHOLD, MACHINERY
  • Referenced by orders.o_custkey
  • c_acctbal can be negative (credit customers)

Example queries

Top customers by account balance

SELECT c_custkey, c_name, c_acctbal, c_mktsegment
FROM customer
ORDER BY c_acctbal DESC
LIMIT 10;

Customers by market segment

SELECT c_mktsegment, COUNT(*) AS cnt, AVG(c_acctbal) AS avg_balance
FROM customer
GROUP BY c_mktsegment
ORDER BY cnt DESC;
