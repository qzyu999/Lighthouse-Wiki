partsupp

Many-to-many relationship between parts and suppliers, with pricing and availability.

Layer: Core Type: Relationship Rows: 8,000 Related: part, supplier

Schema

ColumnTypeDescription
ps_partkeyINTEGERFK → part.p_partkey (part of composite PK)
ps_suppkeyINTEGERFK → supplier.s_suppkey (part of composite PK)
ps_availqtyINTEGERAvailable quantity from this supplier
ps_supplycostDECIMALSupply cost for this part-supplier combination
ps_commentVARCHAROptional remarks

Business rules

  • Composite primary key: (ps_partkey, ps_suppkey)
  • ps_partkey must reference a valid part.p_partkey
  • ps_suppkey must reference a valid supplier.s_suppkey
  • ps_availqty ≥ 0
  • ps_supplycost > 0
  • Each part has ~4 suppliers (8,000 rows / 2,000 parts)

Example queries

Cheapest supplier for each part

SELECT ps.ps_partkey, p.p_name, s.s_name, ps.ps_supplycost
FROM partsupp ps
JOIN part p ON p.p_partkey = ps.ps_partkey
JOIN supplier s ON s.s_suppkey = ps.ps_suppkey
WHERE ps.ps_supplycost = (
  SELECT MIN(ps2.ps_supplycost)
  FROM partsupp ps2
  WHERE ps2.ps_partkey = ps.ps_partkey
)
ORDER BY ps.ps_partkey
LIMIT 10;

Total inventory value by supplier

SELECT s.s_name,
       SUM(ps.ps_availqty * ps.ps_supplycost) AS inventory_value
FROM partsupp ps
JOIN supplier s ON s.s_suppkey = ps.ps_suppkey
GROUP BY s.s_name
ORDER BY inventory_value DESC;
