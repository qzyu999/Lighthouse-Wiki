region

Top-level geographic dimension representing continents in the supply chain.

Layer: Reference Type: Dimension Rows: 5 Related: nation

Schema

ColumnTypeDescription
r_regionkeyINTEGERPrimary key — unique region identifier
r_nameVARCHARRegion name (AFRICA, AMERICA, ASIA, EUROPE, MIDDLE EAST)
r_commentVARCHAROptional remarks

Business rules

  • r_regionkey is the primary key (unique, not null)
  • Exactly 5 rows — one per continent
  • Referenced by nation.n_regionkey
  • Static reference data — never changes after initial load

Example queries

All regions

SELECT r_regionkey, r_name
FROM region
ORDER BY r_regionkey;

Nations per region

SELECT r.r_name, COUNT(*) AS nation_count
FROM region r
JOIN nation n ON n.n_regionkey = r.r_regionkey
GROUP BY r.r_name
ORDER BY nation_count DESC;
