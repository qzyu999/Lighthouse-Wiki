nation

Country-level geographic dimension linking customers and suppliers to regions.

Layer: Reference Type: Dimension Rows: 13 Related: region, customer, supplier

Schema

ColumnTypeDescription
n_nationkeyINTEGERPrimary key — unique nation identifier
n_nameVARCHARCountry name
n_regionkeyINTEGERFK → region.r_regionkey
n_commentVARCHAROptional remarks

Business rules

  • n_nationkey is the primary key (unique, not null)
  • n_regionkey must reference a valid region.r_regionkey
  • Referenced by customer.c_nationkey and supplier.s_nationkey
  • Static reference data — 13 predefined countries

Example queries

Nations with their region

SELECT n.n_name AS nation, r.r_name AS region
FROM nation n
JOIN region r ON r.r_regionkey = n.n_regionkey
ORDER BY r.r_name, n.n_name;

Customer count by nation

SELECT n.n_name, COUNT(*) AS customer_count
FROM nation n
JOIN customer c ON c.c_nationkey = n.n_nationkey
GROUP BY n.n_name
ORDER BY customer_count DESC;
