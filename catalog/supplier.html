supplier

Parts suppliers that provide items to the supply chain.

Layer: Core Type: Entity Rows: 100 Related: nation, partsupp, lineitem

Schema

ColumnTypeDescription
s_suppkeyINTEGERPrimary key — unique supplier identifier
s_nameVARCHARSupplier name
s_addressVARCHARStreet address
s_nationkeyINTEGERFK → nation.n_nationkey
s_phoneVARCHARPhone number
s_acctbalDECIMALAccount balance
s_commentVARCHAROptional remarks

Business rules

  • s_suppkey is the primary key (unique, not null)
  • s_nationkey must reference a valid nation.n_nationkey
  • Referenced by partsupp.ps_suppkey and lineitem.l_suppkey
  • Each supplier can provide multiple parts via the partsupp relationship

Example queries

Suppliers by nation

SELECT n.n_name, COUNT(*) AS supplier_count
FROM supplier s
JOIN nation n ON n.n_nationkey = s.s_nationkey
GROUP BY n.n_name
ORDER BY supplier_count DESC;

Supplier part availability

SELECT s.s_name, COUNT(ps.ps_partkey) AS parts_supplied,
       AVG(ps.ps_supplycost) AS avg_cost
FROM supplier s
JOIN partsupp ps ON ps.ps_suppkey = s.s_suppkey
GROUP BY s.s_name
ORDER BY parts_supplied DESC
LIMIT 10;
