Glossary

Business terms and their technical definitions.

About This Glossary

This glossary provides a shared vocabulary for business and technical concepts used throughout the TPC-H supply chain dataset. Each term includes a plain-language definition and its relationship to the underlying schema. Use this as a reference when writing queries, building metrics, or onboarding new team members.

Business Terms

Term Definition Related Table
Order A purchase request placed by a customer. Each order has a unique key, a date, a priority level, and a total price. An order may contain multiple line items. orders
Line Item A single product entry within an order, specifying quantity, price, discount, tax, ship date, and return status. The most granular fact in the model. lineitem
Customer Segment A classification of the customer's business type. One of: AUTOMOBILE, BUILDING, FURNITURE, HOUSEHOLD, or MACHINERY. customer (c_mktsegment)
Market Segment Synonym for customer segment in the TPC-H model. Used interchangeably in queries like Q3 (Shipping Priority). customer (c_mktsegment)
Order Priority Urgency classification of an order. Values: 1-URGENT, 2-HIGH, 3-MEDIUM, 4-NOT SPECIFIED, 5-LOW. Used in fulfillment scheduling. orders (o_orderpriority)
Ship Mode The transportation method for a line item. Values: REG AIR, AIR, RAIL, SHIP, TRUCK, MAIL, FOB. Affects delivery time and cost. lineitem (l_shipmode)
Return Flag Indicates whether a line item was returned (R), accepted (A), or is still in transit (N). Critical for revenue calculations. lineitem (l_returnflag)
Extended Price The gross price for a line item before discounts and taxes. Calculated as l_quantity × part price. Base for revenue metrics. lineitem (l_extendedprice)
Discount A fractional reduction applied to the extended price (0.00 to 0.10). A value of 0.05 means a 5% discount on that line item. lineitem (l_discount)
Tax A fractional tax rate applied after discount (0.00 to 0.08). Applied per line item, not per order. lineitem (l_tax)
Supply Cost The cost a supplier charges for a specific part. Used to calculate margins (extended price minus supply cost). partsupp (ps_supplycost)
Account Balance A monetary value representing a customer's or supplier's credit standing. Can be negative (debt) or positive (credit). customer (c_acctbal), supplier (s_acctbal)
Order Status O = Open (at least one line item pending), F = Fulfilled (all items shipped), P = Partial (some items shipped, none pending cancellation). orders (o_orderstatus)

Technical Terms

Term Definition Related Table
Fact Table A table storing measurable events at the finest grain. In TPC-H, lineitem is the central fact table with ~6M rows at SF=1. Contains foreign keys to all dimensions. lineitem
Dimension Table A table storing descriptive attributes used to filter or group facts. Examples: customer, supplier, part, nation, region. customer, supplier, part, nation, region
Composite Key A primary key composed of multiple columns. In TPC-H, lineitem uses (l_orderkey, l_linenumber) and partsupp uses (ps_partkey, ps_suppkey). lineitem, partsupp
Foreign Key A column referencing another table's primary key. Example: lineitem.l_orderkey → orders.o_orderkey. Enforces referential integrity. All tables
Cardinality The number of distinct values in a column. High cardinality (e.g., l_orderkey) means many unique values; low cardinality (e.g., o_orderstatus with 3 values) means few. All tables
Scale Factor (SF) The multiplier controlling TPC-H dataset size. SF=0.01 ≈ 60K line items, SF=1 ≈ 6M line items. Our dataset uses SF=0.01 for fast iteration. All tables
