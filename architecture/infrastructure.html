Infrastructure

Compute, storage, and orchestration.

Compute

Processing workloads run on ephemeral clusters that scale based on job size and priority. Batch and streaming engines are supported.

Storage

Object storage serves as the foundation for the lakehouse, with table formats providing ACID semantics and time-travel capabilities.

Orchestration

A DAG-based scheduler coordinates pipeline execution, manages dependencies, handles retries, and provides observability into job status.
