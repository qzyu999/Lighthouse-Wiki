Getting Started

Connect to the data lake and run your first query.

Prerequisites

You need network access to the data platform and valid credentials. Contact your team lead if you do not have an account yet.

Connecting

Use the provided connection string and your credentials to connect via your preferred SQL client or notebook environment.

First Query

Start by querying a gold-layer table to verify your connection. For example: SELECT * FROM gold.customers LIMIT 10.
