Roadmap

What's planned for the TPC-H data platform.

Completed

✅ DuckDB Query Engine Integration

Migrated all TPC-H tables from flat CSV to DuckDB's native columnar storage. Enabled in-process analytical queries with sub-second latency on SF=0.01. Supports full SQL including window functions, CTEs, and predicate pushdown.

Completed: 2024-07-01

In Progress

🔄 Wiki Context Injection into Lighthouse LLM

Feeding wiki page content (table schemas, metric definitions, glossary terms) into the Lighthouse chatbot's system prompt so the LLM can generate accurate SQL against the TPC-H schema without hallucinating column names or relationships.

Target: 2024-08-15 · Owner: Data Platform Team

Planned

📋 Incremental Refresh (Append-Only Ingestion)

Add support for appending new orders and line items without regenerating the full dataset. Enables simulating a live order stream by inserting synthetic rows on a schedule. Prerequisite for real-time dashboards.

Target: Q4 2024 · Depends on: DuckDB WAL support

📋 Materialized Views for Top-N Queries

Pre-compute results for expensive queries like "top 10 suppliers by revenue" and "top 5 customers by order count." Reduces LLM response latency by serving cached results instead of running full aggregations on each request.

Target: Q4 2024 · Depends on: Incremental refresh

📋 Real-Time Order Stream (Bronze Layer)

Introduce a streaming ingestion layer that generates synthetic TPC-H orders in real time. Orders flow into a Bronze (raw) table, get validated and deduplicated into Silver, then aggregated into Gold-layer materialized views. Mirrors a production medallion architecture.

Target: Q1 2025 · Depends on: Incremental refresh, materialized views

📋 Interactive ERD Visualization (Cytoscape.js)

Replace the ASCII entity-relationship diagram on the Lineage Graph page with a draggable, zoomable Cytoscape.js visualization. Clicking a node will show column details, row counts, and sample data inline.

Target: Q1 2025 · Depends on: Wiki context injection

Prioritization

Items are ordered by dependency chain: incremental refresh unlocks materialized views, which unlocks real-time streaming. The wiki context injection is the current priority as it directly improves the Lighthouse LLM's query accuracy.
