daily_revenue

Total revenue per day, computed from lineitem shipments using the TPC-H revenue formula.

Formula

revenue = SUM(l_extendedprice * (1 - l_discount))
FROM lineitem
WHERE l_shipdate IN range

Source

Computed from the lineitem table. Each row represents a shipped line item; revenue is calculated as extended price adjusted for discount. Only shipped items (where l_shipdate falls within the target date range) are included.

Grain

One row per calendar day. The l_shipdate field determines which day a transaction belongs to.

Example

SELECT l_shipdate AS revenue_date,
       SUM(l_extendedprice * (1 - l_discount)) AS daily_revenue
FROM lineitem
WHERE l_shipdate BETWEEN '1995-01-01' AND '1995-12-31'
GROUP BY l_shipdate
ORDER BY l_shipdate;
