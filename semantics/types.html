Type System

Formal definitions for each data primitive type.

Primitive Types

The platform supports STRING, INTEGER, FLOAT, BOOLEAN, TIMESTAMP, and DATE as first-class primitive types with well-defined semantics.

Complex Types

ARRAY, MAP, and STRUCT types allow nesting and composition. Each has defined rules for nullability, equality, and ordering.

Type Coercion

Implicit coercion rules define how values are promoted between compatible types. Explicit casts are required for lossy conversions.
