daily-revenue

Aggregates lineitem and orders data into daily revenue metrics.

Schedule: Daily 07:00 UTC Input: lineitem + orders Output: daily revenue aggregate Owner: analytics

Description

This pipeline reads from the lineitem and orders tables, joins them on l_orderkey = o_orderkey, and computes daily revenue aggregates using the TPC-H formula: SUM(l_extendedprice * (1 - l_discount)) grouped by ship date.

Dependencies

  • lineitem — source fact table (60,000 rows)
  • orders — provides order context and customer linkage

Both input tables must be loaded before this pipeline executes.

Logic

SELECT l.l_shipdate AS revenue_date,
       SUM(l.l_extendedprice * (1 - l.l_discount)) AS daily_revenue,
       COUNT(DISTINCT l.l_orderkey) AS order_count
FROM lineitem l
JOIN orders o ON o.o_orderkey = l.l_orderkey
GROUP BY l.l_shipdate;
